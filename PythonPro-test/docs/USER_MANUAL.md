# Pilot 生产测试系统 · 用户使用手册

本手册面向产线操作人员与系统管理员，按页面说明日常使用方法。开发与二次开发请见
[项目开发说明](PROJECT_GUIDE.md)。

## 1. 系统简介

Pilot 是一套部署在产线工作站上的生产测试系统，把「产品 SN → 测试流程 → 测试执行 →
测试报告 → MES 上传」串成一条可追溯链路：

- 每个 SN 每次测试生成一份独立报告，永久留档（失败报告不会因复测被清除）；
- 已合格的 SN 禁止重复测试，失败复测次数可配置；
- 测试流程低代码编排，保存即固化版本，历史报告不受后续修改影响；
- 支持串口、CAN、TCP、Modbus、蓝牙、MQTT、J-Link 等产品通讯方式（无硬件时可用内置仿真器演示全流程）。

两种角色：

| 角色 | 能做什么 |
| --- | --- |
| 管理员 | 全部功能：流程编排、通讯配置、固件烧录、MES 集成、账号管理、生产测试与报告操作 |
| 操作工 | 生产测试页扫码/执行测试、查看运行状态与测试报告 |

## 2. 登录

1. 浏览器打开 `http://127.0.0.1:8000`。
2. 输入用户名和密码登录。初始账号：`admin / admin123`（管理员）、`operator / operator123`（操作工）。
3. 首次登录后请通过左下角「密码」按钮修改密码。

注意：服务每次重启后所有登录会话失效，需要重新登录（安全策略）；会话有效期 12 小时。

## 3. 生产测试（操作工主页面）

### 3.1 选择测试对象

执行台顶部三个下拉按顺序索引：

1. **产品型号**：与 MES 集成中的产品主数据一致，主数据里有多少启用产品就列出多少（含暂未建流程的产品）。
2. **测试工站**：显示工站主数据中的全部启用工站。
3. **测试流程**：产品与工站选定后，若流程编排中已绑定该组合，自动带出对应流程（横幅显示流程名、版本与测试项数）；未绑定时提示"该产品在当前工站下没有绑定的测试流程"。

选中的测试工站即本次执行工站，会写入运行记录与报告。

### 3.2 扫码与执行

1. 用扫码枪扫描产品 SN（结束符设为 Enter），或手工输入后点击「绑定 SN」。
2. 系统校验 SN 格式、是否已合格、复测次数与工站占用，并给出提示。
3. 点击「开始测试」或按 **F2**。执行中页面实时刷新每个测试项的实测值、判定条件、耗时与结果。
4. 完成后显示 PASS/FAIL 与报告编号；点击「清空 / 下一台」开始下一件。

### 3.3 复测规则

- 已有 PASS 报告的 SN 禁止再测；
- 失败 SN 可复测，次数上限取流程定义的 `max_retests`（未配置时跟随工位策略，默认 3 次）；
- 复测次数按 SN 跨全部流程累计，换流程不能绕过限制；
- 同一工站同一时间只允许一个测试在执行。

## 4. 流程编排（管理员）

### 4.1 流程库（按产品管理）

左侧流程库**按产品分组索引**：每个产品一组（组头显示产品编号、名称与流程数），
有流程的组默认展开；每组组头的「+ 新建」可直接创建关联该产品的流程。
绑定产品已停用或不在主数据中的流程归入末尾分组并标注。

### 4.2 编辑与保存

1. 中间编辑区支持三种方式：**图形画布**（拖入测试项/条件/并行/循环/子流程节点）、**步骤列表**、**高级 JSON**，三者共用同一份草稿。
2. 元信息区设置流程名称、**产品型号**（下拉来自产品主数据）、**绑定工站**（下拉来自工站主数据，"不限工站"表示任意工站可执行）、失败复测次数。
3. 点击「编译校验」检查错误；「保存新版本」后版本号自动 +1。
4. 同一产品在同一工站下只允许一个启用流程。

节点与动作的详细说明见 [控制流说明](CONTROL_FLOW.md)。

## 5. 通讯配置（管理员）

左侧选择协议（仿真器/串口/CAN/TCP/Modbus/蓝牙/WiFi/MQTT/J-Link），右侧配置：

- **连接参数**：串口号、地址端口、波特率等；
- **下发编码**：低代码页面输入的十进制数值如何打包成字节（类型、字节序、缩放）；
- **响应解析**：设备返回字节如何解析为断言可用的数值。

「测试连接」即时验证参数（不要求先保存）；「保存配置」后流程执行时生效。
标记「驱动缺失」的协议需先安装硬件依赖：`uv sync --extra hardware`。

## 6. 固件烧录（管理员)

- **登记固件**：选择本机文件或填写工作站路径，入仓时记录 SHA-256 校验和，防止烧入被替换的文件；「校验」按钮可随时复核。
- **烧录后端**：仿真器（无硬件演示）/ J-Link / 外部命令行工具（如 STM32_Programmer_CLI），保存后可「测试连接」。
- 流程中通过「固件烧录」动作引用已登记固件，烧录记录（固件、校验和、结果、耗时）自动写入报告。

详见 [固件烧录说明](FIRMWARE_FLASH.md)。

## 7. MES 集成（管理员）

### 7.1 产品与工站主数据

MES 是产品型号与工站编号的权威来源。点击「同步产品 / 同步工站 / 全部同步」从 MES
拉取（模拟器模式使用内置示例数据）；表格固定高度、滚动查看。

- 本地添加的行可编辑、删除，不受同步影响；
- MES 同步的行只能启用/停用（权威数据不可本地篡改），MES 端删除后再次同步会自动停用。

主数据为空时，流程的产品/工站保持自由文本模式，便于演示与离线使用。

### 7.2 工位策略

- **工位编号**：本终端的默认工站，下拉候选来自工站主数据（同步后自动更新）；执行台默认选中它。
- **SN 正则校验规则**、**默认操作员**、**失败复测次数上限**、**报告完成后自动上传 MES** 开关。

### 7.3 报告上传接口

配置 MES 接收地址、请求方法、超时、请求头与字段映射模板（支持 `${report_no}`、`${sn}`、
`${items}`、`${report}` 等占位符）；「保存并预览」可查看实际发送的报文结构（不真正调用 MES）。
报告编号作为幂等键写入 `Idempotency-Key` 请求头，MES 端可据此去重。

## 8. 报告中心

- 按 SN 模糊搜索，按测试结果 / MES 状态筛选；
- 「详情」查看完整报告：测试项明细与断言、控制流执行记录、固件烧录记录、MES 上传记录；
- 支持打印、下载 JSON；MES 上传失败的报告可由管理员重试上传。

## 9. 账号权限（管理员）

- 创建账号：用户名（字母开头 2~32 位）、显示名、角色、初始密码（至少 8 位）；
- 重置密码 / 停用启用账号；不能停用自己，且至少保留一个可用管理员；
- 改密、重置、停用后，对应账号的已登录会话立即失效。

## 10. 常见问题

| 现象 | 处理 |
| --- | --- |
| 启动提示端口被占用 | 启动器会自动结束本系统残留的 python 进程；提示无法确认来源时按打印的命令手动释放 |
| 页面显示旧版本 | 按 Ctrl+F5 强制刷新一次（新版本已加缓存控制，之后普通刷新即可） |
| 开始测试报 409「工站不一致」 | 流程绑定工站与执行台所选工站不一致；切换执行台的测试工站，或改流程绑定 |
| 扫码提示禁止重复测试 | 该 SN 已合格或复测次数已用完，属正常管控；需要重测请联系管理员调整策略 |
| 服务重启后要求重新登录 | 安全策略（会话密钥随启动轮换），重新登录即可 |
| 数据保存在哪里 | 启动目录下的 `data/testsystem.db`；可用环境变量 `TESTSYSTEM_DATA_DIR` 指定固定目录（建议固定启动方式或显式设置该变量，避免不同启动目录产生不同数据库） |
